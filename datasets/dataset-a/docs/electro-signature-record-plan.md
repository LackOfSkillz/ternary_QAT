# Electro-signature Dataset A record plan (PROPOSAL)

Candidate **future** Dataset A records derived from the Electro phrase-signature
research. This is a **plan**, not data: no records are created, promoted, or
trained here, and the raw phrase lists are never added to training. Each concept
targets an underlying **craft failure**, not a banned word list — the gold solves
the scene-level problem rather than swapping synonyms.

Every eventual record follows the existing Dataset A schema (origin
`model_authored`, `teacher_model` truthful, `excluded_from_training: true`, an
`invention_budget`, and — for restraint cases — the structured no-change
protocol). Style profiles vary so no single repair becomes house style.

> The governing lesson across all concepts: **reducing a signature is a
> scene-craft act, not a substitution.** A record must never teach "replace phrase
> X with synonym Y."

## A. Lexical substitution failure

- **Setup:** source contains `metallic tang of fear` (embodied + sensory shorthand).
- **Tempting failure (rejected):** `coppery taste of dread` — same generic embodied
  shorthand, merely re-lexicalized. Label `cliche_substitution`.
- **Gold:** solve the scene — show the fear through a specific, character-grounded
  physical particular (what *this* character does with *this* body in *this*
  room), or cut the interiority and let action carry it.
- **invention_budget:** bounded (one concrete scene-specific detail).

## B. Clustered body reactions

- **Setup:** every emotional turn is carried by breath hitching, jaw tightening,
  swallowing hard, trembling hands (embodied cluster).
- **Task:** remove the repetition while preserving **one** earned physical
  reaction; the rest of the emotion moves to dialogue/action/subtext.
- **Rejected:** deletes all physical reaction (over-correction → `imposed_minimalism`)
  or swaps each for a different stock cue.
- **invention_budget:** none (deletion/rearrangement of supplied material).

## C. Dialogue delivery over-tagging

- **Setup:** `voice low`, `voice softening`, `voice hardening`, `voice barely
  audible` recur as tags (dialogue-delivery template).
- **Task:** let dialogue and action carry delivery; keep **enough** attribution to
  track speakers — do **not** strip all tags.
- **Rejected:** removes every tag (reader loses the thread) or keeps them all.
- **invention_budget:** none.

## D. Pressure-metaphor monoculture

- **Setup:** `crushing weight`, `suffocating pressure`, `tension hanging heavy`
  (pressure-metaphor cluster) stand in for evidence.
- **Task:** replace **only** the generic abstractions with concrete scene evidence;
  keep any single earned metaphor.
- **Rejected:** swaps one weight metaphor for another; or flattens all imagery.
- **invention_budget:** bounded (concrete observable evidence).

## E. Gaze choreography

- **Setup:** scene built from `eyes narrowing`, `gaze shifting`, `eyes meeting`,
  `looking away` (gaze cluster).
- **Task:** introduce meaningful action or object interaction **without changing
  the scene outcome**; keep at most one motivated look.
- **Rejected:** substitutes a different eye-movement set; or changes who "wins."
- **invention_budget:** bounded (one motivated action/object beat).

## F. Intensifier accumulation

- **Setup:** stacks `sudden`, `profound`, `absolute`, `utterly`, `sheer`
  (generic-intensifier cluster).
- **Task:** retain only the **load-bearing** intensity; the rest is cut, not
  re-worded.
- **Rejected:** trades one intensifier stack for another; or removes all intensity
  and flattens the voice.
- **invention_budget:** none.

## G. No-change restraint (anti-blacklist)

- **Setup:** a passage contains **one** listed phrase (e.g. `metallic tang`) that
  is **earned and natural** in context.
- **Correct response:** leave it unchanged — the structured no-change object
  (`changed: false`, source text preserved).
- **Purpose:** this record is **essential** to prevent blacklist behavior. It
  teaches that a phrase's presence is not a defect; clustering/repetition is.
- **invention_budget:** none.

## H. Author-voice override

- **Setup:** an author profile demonstrably uses a listed construction
  **intentionally** (declared in the craft constitution / style profile).
- **Correct response:** preserve it despite the generic phrase-risk lexicon;
  precedence rules put the author's established voice above the generic lexicon.
- **Rejected:** "corrects" the author's intentional signature (label
  `converted_voice_to_house_style` / `unauthorized_rewrite`).
- **invention_budget:** none.

## Coverage note

Concepts G and H are the safeguards: without them the corpus would teach a phrase
censor. Concepts A–F each pair a **clustered** failure with a repair that operates
at the scene level, across at least two style profiles, so the model learns to
reduce signatures **contextually** — the same anti-slop doctrine already governing
Dataset A, now informed by the Electro signature families.
