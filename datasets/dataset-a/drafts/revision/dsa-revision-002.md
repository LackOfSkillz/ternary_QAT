## Instruction

Perform a focused anti-slop pass. If the passage has no genuine slop or error,
return it unchanged and say so. Do not rewrite clean prose.

## Context

The generator ran all night in the yard, coughing twice an hour like something
that had learned the trick of breathing. By dawn the fuel was gone. Petra counted
the jars on the shelf, then counted them again, and did not write the number down.

## Gold Response

```json
{
  "changed": false,
  "reason": "No genuine defect found.",
  "text": "The generator ran all night in the yard, coughing twice an hour like something that had learned the trick of breathing. By dawn the fuel was gone. Petra counted the jars on the shelf, then counted them again, and did not write the number down."
}
```

The structured no-change response (see the specification's no-change protocol)
returns `changed: false` with the source text exactly preserved in `text`. The
passage is concrete, its rhythm is controlled, and the withheld number does real
work; there is nothing to fix.

## Protected Elements

- The simile "like something that had learned the trick of breathing" (earned, specific).
- The deliberate repetition "counted… counted again" and the withheld number.
- Sentence rhythm and word choices throughout.

## Rejected Response

```json
{
  "changed": true,
  "reason": "Tightened rhythm and clarified the simile.",
  "text": "The generator ran all night in the yard, coughing every half hour like a failing lung. By dawn the fuel was gone. Petra counted the jars on the shelf twice and didn't write the number down."
}
```

## Rejection Reasons

- `unauthorized_rewrite`: this is a *competent* edit — it reads cleanly — but the
  passage had no genuine defect, so any change violates the instruction. A
  polished rewrite of clean prose is still a rewrite of clean prose.
- `voice_flattening`: the earned simile ("like something that had learned the
  trick of breathing") is normalized into a serviceable-but-generic one ("like a
  failing lung"), trading a distinctive image for a familiar one.
- `converted_voice_to_house_style`: the deliberate repetition ("counted… then
  counted them again") is compressed to "counted… twice," erasing the beat that
  dramatizes Petra's dread; the smoothing is exactly the tempting-but-wrong move.

## Evaluation

- PASS iff the output is the structured no-change object (`changed: false`) whose
  `text` exactly matches the source. (A genuine-error fix would return
  `changed: true` with a minimal correction, but there is no error here.)
- FAIL on any synonym substitution, compressed repetition, or added/removed
  modifier in a sentence that was already precise — even when the result reads
  well.

## Reviewer Notes

Restraint exemplar (the ~10% no-change quota). The whole point is to punish
compulsive rewriting, including *competent* rewriting: the rejected response is a
polished over-edit, not an obviously bad one, so it tests whether the model can
leave clean prose alone. Decision is near-deterministic: the no-change `text` must
equal the source verbatim.
